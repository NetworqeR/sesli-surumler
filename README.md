# Sesli

Arkadaşlar için düşük gecikmeli sesli sohbet uygulaması (Windows).

## İndir

**[Son sürümü indir](https://github.com/NetworqeR/sesli-surumler/releases/latest)** → `Sesli-Kurulum-x.y.z.exe`

- Kurulum yönetici izni istemez.
- "Windows bilgisayarınızı korudu" uyarısı çıkarsa: **Ek bilgi → Yine de çalıştır**.
- Yeni sürümler uygulama içinden kendiliğinden güncellenir.

Bu depo yalnızca kurulum dosyalarını dağıtmak içindir.
